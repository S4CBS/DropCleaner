# Drop Cleaner (NeoForge 1.21.1)

Мод для Minecraft 1.21.1 (NeoForge 21.1.255), который автоматически очищает лежащие на полу предметы каждые **10 минут** (или с настроенным интервалом), отправляет предупреждения в чат и защищает ценные вещи игроков.

---

## ⚡ Особенности

1. **Периодическая очистка**:
   - По умолчанию каждые 10 минут (600 секунд) очищаются брошенные предметы во всех мирах (Overworld, Nether, End, Ultra Space и др.).
2. **Предупреждения в чате**:
   - Сообщения за 60, 30, 10, 5, 3, 2, 1 сек. до очистки.
   - Итоговый отчёт: сколько всего предметов и пачек/стаков было удалено.
3. **Защита от потери ценного дропа**:
   - **Защита свежего дропа (`minimumItemAgeSeconds`)**: предметы, которые упали менее 15 секунд назад (например, игрок только что умер или копает), **не удаляются**!
   - **Защита переименованных вещей**: предметы с кастомным именем (через наковальню) не удаляются.
   - **Защита незерита**: незеритовые слитки, обломки, броня и инструменты защищены.
   - **Защита шалкеровых ящиков**: шалкеры с содержимым не удаляются при падении на пол.
   - **Белый список**: по умолчанию защищены Незер-звезда, Яйцо дракона, Элитры, Маяк, Тотем бессмертия.
4. **Команды управления**:
   - `/dropclean time` (или `/cleardrop time`, `/clearlag time`) — узнать оставшееся время до следующей очистки (доступно всем игрокам).
   - `/dropclean clear` (или `/dropclean now`) — принудительно запустить очистку прямо сейчас (уровень прав: OP / читы).
   - `/dropclean reload` — перезагрузить файл конфигурации `config/dropcleaner.json` без перезапуска игры.

---

## ⚙️ Конфигурация (`config/dropcleaner.json`)

Файл конфигурации создается автоматически при первом запуске в папке `.minecraft/config/dropcleaner.json`:

```json
{
  "intervalSeconds": 600,
  "minimumItemAgeSeconds": 15,
  "warningSeconds": [60, 30, 10, 5, 3, 2, 1],
  "broadcastWarnings": true,
  "broadcastCleanup": true,
  "protectNamedItems": true,
  "protectNetherite": true,
  "protectShulkerBoxes": true,
  "protectedItems": [
    "minecraft:nether_star",
    "minecraft:dragon_egg",
    "minecraft:elytra",
    "minecraft:beacon",
    "minecraft:totem_of_undying"
  ]
}
```

---

## 🔨 Сборка

Запустите в PowerShell:
```powershell
.\build.ps1
```
Скрипт скомпилирует исходники и поместит готовый `.jar` в `build/libs/` и скопирует в `%APPDATA%\.minecraft\mods\`.
